## About

I'm a software developer based in Morocco. My work spans the full stack: React and Next.js on the front end, Go and Express on the back end, and SQL or document databases underneath.

What sets my work apart is the deployment side. I manage Linux servers, containerize workloads with Docker, and configure Nginx reverse proxies and Cloudflare so an application goes from development to production without hand-offs.

I'm currently building at Zone01 Oujda and open to software engineering roles, freelance projects and technical collaborations.
